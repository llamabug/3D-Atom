# 3D-Atom
A 3D atom built in Three.js


I'd never worked with three.js, and I would not consider myself that great at regular js anyway. <br> This project started with me following a tutorial, and then I started on my own thing. <br> Initially, I made an atom with orbiting electrons and a nucleus that spun on scroll. There were also info sections and a part at the top where you could jump to a specific section.
<br> I then changed. The nucleus became stationary but would zoom in/out, and zooming in made it more transparent so that the viewer can see protons/neutrons on the inside. I also went to 2 text boxes only, 1 with buttons that would change the text of the other.
<br> This project was really fun- a lot more than I initially expected, and I learned a lot about javascript along the way.

<h3>TroubleShooting</h3>
I encountered a few problems along the way. When I made the donut, it was huge compared to the cube and so I had to figure out how to resize, but solving this made it a lot easier to understand what I was doing in later challenges. I had errors in the image textures on the atom - especially when it came to uploading to GitHub (NB the code around that has come from chatGPT but it's more just to ensure it works properly-- my original code was much simpler but didnt work -_-). I also had problems with the camera but found many tutorials and I was able to work it out in the end. Sometimes animation was quite clunky but this was just a matter of adjusting numbers, and there were some challenges with the css styling of the website but these were more annoying things compared to the issues with js.
